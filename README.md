# 뉴스피드 서비스: 실시간 소셜 피드 플랫폼

## 프로젝트 소개

이 프로젝트는 실시간으로 업데이트되는 뉴스피드를 제공하는 소셜 플랫폼입니다. 사용자는 게시물을 작성하고, 댓글을 달며, 다른 사용자를 팔로우할 수 있습니다. 또한, 팔로우한 사용자의 게시물을 실시간으로 확인할 수 있습니다.

<br>

## 주요 기능
1. 사용자 계정 관리: 회원가입, 로그인, 로그아웃, 회원탈퇴 등 계정과 관련된 기능
2. 사용자 프로필 관리: 사용자 프로필 정보 수정 및 관리 기능
3. 게시글 관리: 사용자가 작성한 게시글의 생성, 수정, 조회, 삭제 기능
4. 댓글 관리: 게시글에 달린 댓글의 생성, 수정, 조회, 삭제 기능
5. 팔로우 관계 관리: 사용자 간의 팔로우 및 언팔로우 관계 설정 기능
